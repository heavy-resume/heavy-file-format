# Plugin Components #
Host-resolved extension block rendered in normal document flow.
plugin is the required plugin identifier; pluginConfig is optional plugin-owned metadata.
The body is plugin-owned free-form text and must be preserved verbatim rather than interpreted as Markdown or HVY.
pluginSortValues and pluginGroupValues declare source values for the owning reusable list item. Keys must match sortValueDefs/groupValueDefs; sort declarations accept strings or finite numbers, group declarations accept strings. Enum declarations may supply a configured stored value or label. Edit these declarations instead of the derived item keys. Host plugins can use ctx.sortValues.get/set/clear and ctx.groupValues.get/set/clear to update them while preserving editor focus.
If the plugin is unavailable, clients should preserve the block and show an unavailable-plugin placeholder.

# Sections #
Sections are document-root regions containing ordered components.
Section titles name regions for editing and linking; they are not viewer headings.
Sections can be addressed by id and may carry description, tags, layout location, and CSS metadata.
Sections should encompass atomic thoughts. They are intended to be reorganized based on the viewer.
Use containers to group related components within a section.
Use children-order.json to reorder the section's components.

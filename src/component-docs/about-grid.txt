# Grid Components #
Lays out child components visually like a CSS grid.
Use grid/children-order.json to reorder grid items.
gridColumns is a number controlling the column layout.
gridStackWidth controls when responsive renderers switch to a single-column stack. Use a CSS length like 30rem or the literal never. It defaults to 50rem.
gridItems holds ordered grid slots; readers tile items across gridColumns and wrap to new rows.
Each numbered grid slot carries slot metadata; the child block is nested one level deeper.
Grid slot css styles the cell wrapper. Use surface-responsive declarations such as max-md:order: 1; to change cell layout below a document breakpoint.

# Scripting Plugins #
Executes sandboxed Brython/Python source from script.py.
The component body is top-level script source and is exposed as script.py in the CLI.
Scripts run wrapped in a generated function with a doc global, so return can stop a script early.
Scripts also receive a run_context global describing the run. run_context.invoke_reason names what prompted a scripting block to run: load, edit, ai-edit, script-edit, or unknown, which includes entering a view; it is None in form and button scripts. Return early only for specific reasons the script can skip, because the first run in a view may not report load.
Scripts also receive a session global with ephemeral state for the open document: session.state is a dict-like store shared by every script and plugin in the document and kept between runs, never saved, never marked as a document change, and untouched by undo and redo; it starts fresh when a different document is loaded. It holds JSON values only, and a value read from it is a copy: after changing a list or dict, assign it back. session also exposes id, start_time (an aware datetime; requires the datetime library), timezone, and locale.
Use doc helpers for document data, header metadata, attachments, database access, rerendering, and supported document tools.
Use the checked datetime library for the current client time, for example datetime.now().astimezone() or datetime.now(timezone.utc). The older doc.time helpers are deprecated aliases.
Use print(...) to write debugging notes to the script run log.
Imports, network access, and direct DOM/window access are restricted by the scripting sandbox.
Python's getattr, hasattr, setattr, and delattr builtins are available for public attributes; private scripting-runtime attributes are restricted.
Checked script libraries in pluginConfig.libraries are imported before the script runs; this reference client supports random, re, datetime, zoneinfo, and tzlocal.
The checked random library exposes random, shuffle, choice, randrange, randint, uniform, sample, and choices; it does not expose random state, byte generation, cryptographic helpers, or specialized probability distributions.
Installed plugins may expose synchronous methods through doc.plugins.call(plugin_id, method, args). Callback functions may be nested in args and may be invoked later by the plugin; delayed callbacks retain this script's limits and error reporting. A callback shares its script's step budget until none of that script's code has run for 3 seconds, then its next call starts with a full budget.
The checked datetime library exposes date, datetime, timedelta, timezone, and UTC with CPython semantics, including now(), timestamps, ISO parsing with offsets, strptime/strftime with %z and %Z, aware arithmetic and comparisons, astimezone(), weekday(), and isocalendar().
The checked zoneinfo library provides ZoneInfo(key) for IANA zones with per-instant daylight-saving offsets, and tzlocal provides get_localzone() and get_localzone_name() for the viewer's zone.
pluginConfig.maxSteps controls the runtime step budget and defaults to 100000.
Use form plugin scripts when the script is specifically attached to form state or submit behavior.
